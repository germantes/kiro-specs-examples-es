# 📝 Kiro Specs Examples (ES)

Bienvenido a la colección de ejemplos de **Especificaciones (Specs) para Kiro** en español.

El superpoder de Kiro (el IDE de AWS) es el *Spec-Driven Development*. En lugar de escribir código directamente, los desarrolladores escribimos una "Especificación" detallada de lo que queremos, y la IA genera la implementación. 

Este repositorio contiene ejemplos de cómo redactar buenos Specs en español para que Kiro genere código preciso, seguro y escalable.

## 📂 Ejemplos en este repositorio

1. ☁️ `infra-pipeline-aws-spec.md`: Ejemplo DevOps para crear un pipeline de CI/CD hacia AWS.
2. 🔐 `auth-api-spec.md`: Ejemplo Backend para crear un sistema de login seguro.

## 💡 ¿Cómo escribir un buen Spec para Kiro?
- **Contexto claro:** Explica qué quieres lograr.
- **Requisitos técnicos:** Define las herramientas, lenguajes y frameworks.
- **Criterios de aceptación:** Qué debe cumplir el código para considerarse válido.
- **Restricciones:** Qué NO debe hacer la IA.
